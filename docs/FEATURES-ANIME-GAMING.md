# Anime- & Gaming-Features

Ideensammlung – Priorität: 🔥 = MVP der Phase 6, ⭐ = danach, 💡 = später/vielleicht.

---

## 🌸 Für Anime-Fans

| Feature | Beschreibung | Prio |
|---|---|---|
| **Shino-chan – das Maskottchen** | Eigenes Maskottchen (kein Lizenzproblem!), sitzt in der Sidebar, reagiert auf Aktionen (Download fertig → jubelt, RAM voll → schwitzt, Inkognito → Ninja-Outfit). Abschaltbar. | 🔥 |
| **Anime-Tracker** | Verbindung zu **AniList** und **MyAnimeList**: erkennt auf Streaming-Seiten die Folge und markiert sie nach dem Schauen automatisch als gesehen | 🔥 |
| **Episoden-Countdown** | Widget auf der Startseite: „Nächste Folge von X in 2 T 4 Std“ | 🔥 |
| **Saison-Kalender** | Übersicht der aktuellen Anime-Saison (Daten über AniList-API) | ⭐ |
| **Manga-Lesemodus** | Bilder-Seiten als Endlos-Scroll oder Doppelseite, Rechts-nach-links-Modus, Vorladen der nächsten Kapitel | ⭐ |
| **Untertitel-Styler** | Eigene Schrift/Größe/Farbe für Untertitel in HTML5-Videos | ⭐ |
| **Kino-Modus / PiP+** | Bild-in-Bild „immer im Vordergrund“, Lautstärke-Boost, Intro-Überspringen-Taste | 🔥 |
| **Anime-Themes & Live-Wallpaper** | Sakura, Neon-Tokyo, Cyberpunk, Lo-Fi-Zimmer – mit Partikeln (Blütenblätter, Regen) | 🔥 |
| **Japanisch-Helfer** | Hover über japanischen Text → Lesung (Furigana) + Übersetzung | 💡 |
| **Watch-Party** | Videos synchron mit Freunden schauen + Chat | 💡 |
| **Seiyuu-/Charakter-Suche** | Rechtsklick auf Bild → „Welcher Anime ist das?“ (z. B. über trace.moe) | ⭐ |

## 🎮 Für Zocker

| Feature | Beschreibung | Prio |
|---|---|---|
| **Gaming-Modus** | Erkennt laufende Spiele (Prozessliste/Vollbild) und drosselt Shinoho automatisch (RAM, CPU, Netz) – nach dem Spiel alles zurück | 🔥 |
| **Free-Games-Feed** | Widget: aktuelle Gratis-Spiele (Epic, Steam, GOG, Prime Gaming) | 🔥 |
| **Sale-Radar** | Wunschliste mit Preisalarm (z. B. über IsThereAnyDeal-API) | ⭐ |
| **Release-Kalender** | Kommende Spiele-Releases | ⭐ |
| **Sidebar-Messenger** | Discord, Twitch-Chat, WhatsApp, Telegram als Sidebar-Panels | 🔥 |
| **Twitch/YouTube-Live-Benachrichtigungen** | „Dein Streamer ist live“ | ⭐ |
| **RGB-Sync** | Akzentfarbe synchron mit Tastatur/Maus (Razer Chroma, OpenRGB, Corsair iCUE) | ⭐ |
| **Ping-Wächter** | Zeigt Ping/Netzlast an; warnt, wenn Browser-Downloads das Spiel stören | ⭐ |
| **Streamer-Modus** | Blendet persönliche Daten (E-Mail, Lesezeichen-Namen, Adressleiste) beim Streamen aus | 🔥 |
| **Controller-Steuerung** | Browser mit Gamepad bedienen (Tabs wechseln, scrollen) – super für Couch & Steam Deck | ⭐ |
| **Overlay-Browser** | Kleines Browser-Fenster per Hotkey über dem Spiel (für Guides/Wikis) | 💡 |

## 🏆 Für alle – „Spaß-Ebene“

| Feature | Beschreibung | Prio |
|---|---|---|
| **Achievements & Level** | Browser-Erfolge („100 Tabs geschlossen“, „Erste Mod installiert“) + XP-Level mit freischaltbaren Themes | ⭐ |
| **Soundpacks** | 8-Bit, Mecha, Kawaii, Samurai, Sci-Fi | 🔥 |
| **Tastatur-Combos** | Eigene Shortcuts inkl. „Combo“-Gesten (Konami-Code → Easter Egg 😉) | ⭐ |
| **Profile** | „Zocken“, „Anime“, „Schule/Arbeit“ – jedes mit eigenem Theme, Lesezeichen, Sidebar | ⭐ |
| **Boss-Taste** | Ein Tastendruck → alles Verdächtige minimieren/stummschalten | ⭐ |

---

### Rechtliche Hinweise
- Keine geschützten Figuren/Logos in offiziellen Themes. Community-Mods sind Sache der Ersteller.
- APIs (AniList, MAL, IsThereAnyDeal, Twitch …) nur gemäß deren Nutzungsbedingungen verwenden.
