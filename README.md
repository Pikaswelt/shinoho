# 🌸 Shinoho

**Shinoho** ist ein schneller, komplett anpassbarer Browser für **Anime-Fans und Gamer**.
Modifizierbar wie Opera GX, mit eingebautem VPN, Lesezeichen, Inkognito-Modus und
einstellbarer Performance – für Windows, Linux, macOS, Android und iOS.

> Status: **Planungsphase** – es gibt noch keinen Code, nur den Plan.
